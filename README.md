# virtual_sensor

📊 Development of a Virtual Sensor for Real-Time Ash Measurement Prediction in Paper Manufacturing
This project involves the development of a virtual sensor based on a Random Forest Machine Learning model, aimed at predicting the real-time ash measurement values in the paper manufacturing process. By using 12 critical process variables, the model is able to make accurate real-time predictions, enabling more effective control of ash levels during production.

The primary goal of this system is to provide an ash control solution, contributing to a significant reduction in direct paper manufacturing costs by optimizing the process and minimizing material waste.

🎯 General Objective
Develop a virtual sensor using a Random Forest Machine Learning model to predict real-time ash values in the paper manufacturing process, with the goal of optimizing process control and reducing direct manufacturing costs.

🔧 Technologies Used:

Python (for model development and training)
Random Forest (Machine Learning model)
Data analysis libraries: Pandas, Scikit-learn
Real-time database (for integration and continuous prediction)

🎯 Impact:

Cost reduction in paper production by optimizing ash control.
Process efficiency improvement through continuous prediction and adjustment of critical variables.
Implementation of an automated system for real-time monitoring and decision-making.
